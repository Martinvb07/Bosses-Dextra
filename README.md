# Bosses Dextra

Configuracion de los bosses del servidor.

| Carpeta | Que hay |
|---|---|
| `MythicMobs-3D/` | MythicMobs para el servidor **con texturas**: modelos 3D (ModelEngine), animaciones, sonidos propios, bossbar y titulos personalizados. Va con `Modelos/` y el resource pack |
| `MythicMobs-Normal/` | La misma configuracion **solo vanilla**, para el servidor sin texturas: sin modelos ni sonidos propios |
| `Modelos/` | Modelos 3D, texturas, HUD, sonidos y vistas previas de cada boss |
| `ConditionalEvents/` | Apariciones programadas de los bosses |
| `tools/` | Scripts que generan modelos, texturas, sonidos y eventos |
| `NOTAS.md` | Ideas y temas pendientes |

Los cambios que no dependen de las texturas (drops, mensajes, equipo, arreglos) se hacen en las dos carpetas de MythicMobs.
